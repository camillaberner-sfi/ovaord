# Vecka 44 - Hållbarhet

På nätet = digitalt, på Internet
Återbruka = använda igen på ett nytt sätt
Unik = speciell, det finns bara en av den som är unik
Symaskin = en maskin som man använder för att sy kläder
Sy om = Ändra till ett nytt plagg
Stressigt = ont om tid
Klicka hem = beställa saker på internet
Växa ur = kläder blir för små
Slöseri = motsatsen till spara
Resurser = sådant som vi använder för att leva, till exempel pengar
Transport = olika sätt att köra saker, till exempel lastbil eller tåg

# Vecka 40 - Ekonomi
inkomst = Pengar som kommer in.  Pengar som jag tjänar.
utgift = Pengar som går ut. Pengar som jag betalar. 
hushåll = där en eller flera personer bor tillsammans

nödvändig = något som jag måste ha eller betala
ekonomi = handlar om pengar och resurser
